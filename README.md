# MedSurgical Equipamentos

## Sobre o projeto

O MedSurgical Equipamentos é um projeto acadêmico de desenvolvimento front-end que simula um catálogo de uma empresa fictícia de equipamentos médicos e cirúrgicos.

O objetivo é apresentar produtos e categorias de maneira organizada, proporcionando uma experiência de navegação simples e acessível.

## Público-alvo

Estudantes, profissionais da saúde, clínicas, hospitais e pessoas interessadas em conhecer equipamentos médicos.

## Funcionalidades

- Apresentação de categorias de equipamentos.
- Catálogo de produtos e preços ilustrativos.
- Imagens e recursos de mídia.
- Formulário demonstrativo de avaliação de produtos.
- Organização do conteúdo em uma interface web.

Os preços e as informações apresentados possuem finalidade acadêmica e não representam ofertas comerciais reais.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como visualizar o projeto

1. Acesse o repositório no GitHub.
2. Baixe ou clone o projeto.
3. Abra a pasta do projeto no Visual Studio Code.
4. Abra o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para executar o site em um servidor local.

## Privacidade e responsabilidade

O catálogo pode ser consultado sem cadastro. O formulário de avaliação possui finalidade demonstrativa e não deve ser utilizado para coletar dados pessoais reais sem que seu funcionamento, sua finalidade e suas medidas de segurança estejam adequadamente definidos.

## Acessibilidade e sustentabilidade

O projeto considera recursos como organização semântica do HTML, textos alternativos, rótulos de formulários e legendas de vídeo.

Como melhorias futuras, pretende-se ampliar os testes de acessibilidade, revisar o contraste visual e otimizar imagens e vídeos para reduzir o consumo de dados.

## Créditos e materiais externos

O projeto foi desenvolvido para fins acadêmicos, com apoio do ChatGPT na compreensão de conceitos e na revisão de soluções de desenvolvimento.

Os materiais externos utilizados, incluindo imagens, vídeos, legendas e referências, devem ter sua origem e suas condições de uso verificadas e documentadas.

Materiais cuja licença não possa ser confirmada deverão ser substituídos ou utilizados somente após a obtenção de autorização adequada.

## Uso de inteligência artificial

O ChatGPT foi utilizado como ferramenta de apoio ao aprendizado e ao desenvolvimento. As sugestões recebidas devem ser revisadas e adaptadas pelo estudante, que permanece responsável pelo conteúdo e pelo funcionamento do projeto.
